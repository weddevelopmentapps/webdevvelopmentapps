| هدف التكليف | الواقع | المبرر |

| Service Worker وتجهيز offline | لا SW | الملف مكتفٍ بذاته: يعمل دون اتصال بطبيعته (المتطلب الجوهري للبروفة)؛ SW يضيف خطر تقادم نسخ دون فائدة على file://. زر «تجهيز العرض دون اتصال» في الإدارة يفحص اكتمال الوسائط المجاورة. عند تحول النشر المستضاف إلى القناة الأساسية يُضاف SW بنطاق مقيد وفق ARCHITECTURE §7 |

## 4. سلاسة الحركة

- انتقالات المشاهد CSS transform/opacity فقط (تسريع عتادي، لا layout thrash).
- عدّ الأرقام requestAnimationFrame بمدة ≤950ms عند أول دخول فقط ثم ثبات كامل.
- الرسوم `animationDuration: 300` وتُعطل كلياً مع prefers-reduced-motion.
- مقاسات الرسوم يعاد حسابها بعد ملء الشاشة وتغيير القياس (registry.resizeAll بمِؤخّر 120ms).
- فيديو واحد كحد أقصى في التطبيق كله؛ يتوقف تحميله مع reduced-motion/Save-Data.

## 5. الذاكرة والتخلص

  بعد اكتشاف تراكم مستمعين في مراجعة الملاحق — انظر QA_REPORT).
