# لوحة معلومات السكن الجماعي للأفراد في مدينة الرياض — عرض أمين المنطقة

عرضٌ تقديمي تنفيذي سينمائي كامل الشاشة (16:9) مبني كآلة مشاهد، مع إدارة محمية
لدورة «مسودة ← فحص ← معاينة ← نشر إصدار غير قابل للتغيير ← تراجع» — في ملف
HTML واحد مكتفٍ بذاته يعمل بالنقر المزدوج ودون اتصال.

## التشغيل الفوري

| ماذا تريد؟ | كيف |
|---|---|
| **عرض البروفة الآن** | افتح `index.html` في Chrome/Edge → «بدء العرض التقديمي» |
| جلب وسائط الغلاف السينمائية | `bash tools/fetch_media.sh && python3 build.py` (يحتاج اتصالاً — انظر MEDIA_MANIFEST) |
| الإدارة | افتح `index.html#/admin` (أول دخول يهيئ عبارة مرور الوضع المحلي) |
| إعادة توليد البيانات من الورقة | `python3 generate_data.py && python3 build.py` |
| استيراد ورقة جديدة (المسار الموثوق) | `python3 tools/import_workbook.py <الملف.xlsx>` |
| الاختبارات | `node --test "tests/unit/*.test.mjs"` · `node tests/e2e/navigation.spec.mjs` · `node tests/e2e/admin.spec.mjs` |
| النشر المستضاف | انسخ `.github-workflow-deploy.yml` إلى `.github/workflows/` — ينشر `dist/` |

## مفاتيح العرض (جهاز التقديم)

التالي: PageDown / مسافة / Enter / ⬅ / ⬇ · السابق: PageUp / Backspace / ➡ / ⬆ ·
Home الغلاف · End الخاتمة. التفاصيل الكاملة في `docs/PRESENTER_GUIDE_AR.md`.

## الخريطة

| المسار | المحتوى |
|---|---|
| `generate_data.py` | مصدر الحقيقة: مراسي الورقة V1 + 133 بوابة مطابقة تُفشل البناء |
| `data/release.json` | الإصدار المنشور المضمّن (مولَّد — لا يحرَّر يدوياً) |
| `src/` | المصدر: أنماط، نواة، بيانات، رسوم، مقدِّم (12 مشهداً + 5 ملاحق)، إدارة |
| `build.py` → `index.html` | الضم الكامل (خطوط + ECharts + بيانات) |
| `supabase/` | حزمة الإنتاج: هجرات + RLS + دالة نشر + اختبارات + دليل تفعيل |
| `tools/` | استيراد موثوق، قالب ورقة، جلب وسائط، لقطات QA |
| `tests/` | وحدات (مطابقة/اشتقاق/تنسيق) + e2e (ملاحة/إدارة) |
| `docs/` | التدقيق، المطابقة، السيناريو، الأدلة، القواميس، تقارير QA والأداء |
| `private-sources/` | ورقة البيانات الأصلية — **لا تُنشر أبداً** (يستثنيها سير النشر) |

## غير القابل للتفاوض

- المقدِّم يقرأ إصداراً منشوراً واحداً غير قابل للتغيير — لا مسودات ولا أدوات تحرير في العرض.
- لا رقم في الواجهة إلا من الإصدار عبر المنسق المركزي؛ الترتيب على القيم غير المقربة.
- لا تلفيق: وحدات بلا مصدر معتمد (الركائز السبع، المؤشرات، الخطوات القادمة) تعرض
  حالة اعتماد شريفة ويُحجب نشرها ببوابات آلية حتى ورود «خطة عمل المشروع V.1.0.0».
- الخريطة توضيحية وموسومة كذلك في كل استخدام.

الحالة التسليمية الكاملة والعوائق: `docs/QA_REPORT.md` §الخلاصة.
