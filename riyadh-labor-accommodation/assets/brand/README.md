# أصول الهوية — أمانة منطقة الرياض

| الملف | الاستخدام |
|---|---|
| `logo-full.png` | الشعار الكامل (الرمز + «أمانة منطقة الرياض» + Riyadh Region Municipality) — الأسطح الفاتحة |
| `logo-mark.png` | الرمز الدائري وحده — الأيقونات والرؤوس المضغوطة والطباعة |
| `logo-white.png` | نسخة بيضاء أحادية — الرؤوس الداكنة وشريط النمط الهندسي |

**المصدر:** مستخرَجة من منصة «الخدمات البلدية للمشاريع الكبرى — أمانة منطقة الرياض»
(`riyadh-giga-services/index.html`) في هذا المستودع نفسه، بتوجيه مباشر من العميل.
أُزيلت الخلفية البيضاء (شفافية)، وقُصّت الحدود، واشتُقت نسختا الرمز والأبيض برمجياً.

**التضمين:** `build.py` يقرأ هذا المجلد ويحقن الملفات الموجودة في `window.BRAND`
كـ data URIs؛ استبدال أي ملف هنا يكفي لتحديث الهوية دون تغيير سطر كود واحد.
موقع `alriyadh.gov.sa` محجوب على بوابة الشبكة في بيئة التنفيذ، فلم يُستخدم مصدراً.
