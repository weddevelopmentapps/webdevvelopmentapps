# Section Playbook — أطر العمل والمنهجيات + نبذة عن ديلويت + الشروط والأحكام + المستندات القانونية

## 1. ملحق: أطر العمل والمنهجيات (frameworks, ~60 slides)

A curated methodology library proving depth behind the approach. Selection, not
creation: pick framework slide-sets from the reference library to cover every approach
track theme.

### Selection map (scope theme → framework families)

| RFP scope theme | Framework slides to include |
|---|---|
| سياسات عامة / دراسات | Policy-cycle framework (7 مراحل)، أسئلة صناع السياسات، أدلة السياسات في المملكة |
| استراتيجية / تحديث استراتيجيات | StrategyByDesign© ribbon، بيان الطموح، Strategy Cascade، أمثلة عالمية |
| تحليل استراتيجي | SWOT + إثبات فعاليتها، PESTEL، إطار تقييم القطاعات |
| مقارنات معيارية | Benchmarking sources & criteria، احتياجات المؤشرات المعيارية، مصادر ديلويت |
| مبادرات ومشاريع | تقييم الجاهزية، مصفوفة الأولويات بالأوزان، نموذج تحديد الأولويات |
| نموذج تشغيلي | TOM 10-component wheel + محور-by-محور detail slides، أمثلة نماذج تشغيلية |
| حوكمة | إطار الحوكمة المؤسسية، مصفوفة الصلاحيات (توزيع السلطات) |
| إجراءات وعمليات | إعادة تصميم الإجراءات (3 خطوات)، رفع نضج الإجراءات، BPM قصص نجاح، 354 إجراء case |
| قياس أداء | إطار إدارة الأداء المتكامل، خريطة القيمة للقطاع العام، لوحات المتابعة التفاعلية |
| إدارة التغيير / تمكين | إطار إدارة التغيير، Culture Path، منهجية نقل المعرفة |
| إدارة محافظ وبرامج | إدارة المحفظة الاستراتيجية، تنفيذ البرامج الضخمة، مستويات النضج، الأدوار والمسؤوليات، PMO منصة |
| رقمنة / ابتكار / ذكاء اصطناعي | المحفز الرقمي، Deloitte Score، شبكة مكاتب الابتكار، أدوات الابتكار |
| سيناريوهات / استشراف | منهجية الصورة الكاملة في تخطيط السيناريوهات |
| مخاطر | خطة إدارة المخاطر الممنهجة |

The **fixed six** are always included (they also appear inside the approach chapter):
project-management mechanism, risk management, escalation plan, quality plan,
collaborative working, knowledge transfer.

### Framework slide conventions (archetype S)

- Title = assertion of what the methodology achieves — never a bare name
  (`تجمع منهجية السياسات العامة الخاصة بشركة ديلويت بين المستويات المختلفة لعملية صنع
  القرار من خلال عملية مستمرة من التغذية الراجعة…`).
- EN framework names stay Latin inside the Arabic title (`StrategyByDesign©`, `SWOT`,
  `PESTEL`, `Culture Path`).
- `للتوضيح` teal tag on illustrative/mocked visuals; real screenshots for platforms.
- Stage color coding: blue `007CB0` → teal `0D8390` → navy `0F2837` for progressive
  stages; green family for Deloitte-owned process steps; tints `F2F8E5`/`E5F0F9` for
  matrix cells.
- Question bullets (`كيف يمكننا…؟`) appear ONLY under framework stage diagrams.
- When drawing a NEW framework diagram, clone the nearest archetype's geometry (stage
  ribbon / cycle wheel / cascade / matrix / component wheel / maturity ladder) so it is
  indistinguishable from library slides.

## 2. ملحق: نبذة عن ديلويت (~11–12 slides — fixed pack, reuse verbatim)

Canonical sequence (archetype T variants):
1. `ديلويت هي أكبر شركة خدمات مهنية في العالم` — 5 stat cards (green outline icons,
   `67.2 مليار` revenue, `460,000+` staff, `92,000+` new hires, `150+` countries,
   `416 مليون` social investment) + `السنة المالية {YYYY}` green sub-line.
2. Global revenue slide (`وصلت الإيرادات العالمية التراكمية في {YYYY} إلى …`).
3. `تمتلك ديلويت خبرة تقارب 100 سنة في الشرق الأوسط`.
4. `تمتلك ديلويت أكثر من 7000 موظف متخصص عبر 15 دولة في الشرق الأوسط` (region map).
5. First-office history slide (1926).
6. NSE structure slide.
7. `تقدم ديلويت خدماتها عبر 4 أبعاد رئيسية`.
8. `تركز ديلويت على 5 مجالات عمل رئيسية و20 قطاعاً في السوق العالمية`.
9. Transformation positioning slide.
10. AI Institute slide + Trustworthy AI slide.
Update only: fiscal-year numbers when a newer library version exists. Never restyle.

## 3. ملحق: الشروط والأحكام (~12 slides — legal pack, verbatim)

Title `الشروط والأحكام` + subtitle `فيما يلي الشروط والأحكام العامة لشركة ديلويت`.
Numbered clauses (1., 1.1, 1.1.1) at 8–9pt across the width, right-aligned. Reuse the
library pack untouched — never rewrite, summarize, or "improve" legal text. Flag to the
user if the RFP requires different terms.

## 4. ملحق: المستندات القانونية (~10 slides + closer)

One certificate per slide, title `المستندات القانونية | {اسم الشهادة}`:
السجل التجاري، شهادة العضوية في الغرفة التجارية، شهادة ترخيص استثمار خدمي، شهادة
الزكاة والدخل، شهادة التسجيل في ضريبة القيمة المضافة، شهادة المؤسسة العامة للتأمينات
الاجتماعية، شهادة الالتزام بحماية الأجور، شهادة التوطين، رخصة البلدية.
Scan centered, fit to body zone, thin border. **Check validity dates** — flag expired
certificates to the user; never doctor a scan.

Final slide of the deck: the fixed Deloitte legal disclaimer text page (`د إم إي هي
شركة تابعة لديلويت شمال جنوب أوروبا…`) — always last, reuse verbatim.
