# Section Playbook — أطر العمل والمنهجيات + نبذة عن ديلويت + الشروط والأحكام + المستندات القانونية

## 1. ملحق: أطر العمل والمنهجيات (frameworks, ~50–60 slides)

The "methodology arsenal": every framework the approach/PoV chapters *name*, the
appendix *proves* as real, drawn, branded IP. ~95% reusable library — 11+ framework
slides are byte-identical across the reference decks; only footers and the © year
change. **Never invent new Arabic text for an existing framework — reuse verbatim;
that is what the firm itself does.** Target 15–25 slides for a lean deck, up to 60
for a full one; 1 slide per framework, **3 for the engagement's flagship framework**
(the triptych: overview → per-phase definitions → per-phase key questions, the third
title starting with `و…`).

### Universal scaffold (every framework slide)

- Standard header band + **28pt BOLD white** assertion title (this appendix bolds its
  titles; no green highlight, no `(1/N)`, no `|` breadcrumbs here).
- **`للتوضيح` tag** — small rectangle at the exact top-LEFT corner, fill **`0097A9`**,
  white text — on EVERY slide of the section (its compliance marker: "our IP, shown
  illustratively"). No `المصدر:` lines and no `غير شامل` in this appendix.
- Optional kicker under the band, 12–14pt gray, formally naming the framework
  (`إطار عمل منهجية التحليل الرباعي: منهجية توضيحية`).
- Standard footer triplet.

### Title molds (never a bare framework name)

1. Composition count: `يتكون اطار ديلويت لـ{X} من {N} مكونات رئيسية`
2. Function/benefit: `تعمل منهجية مونيتور ديلويت لـ{X} بشكل شامل ومتكامل باستعمال
   اطار {LatinName©}`
3. Usage declaration: `يتم اتباع منهجية {X} الخاصة بمونيتور ديلويت للتوصل إلى…` /
   `نعتمد على إطار عمل {X} من أجل…` / `سنستفيد من…`
4. Proof-of-effectiveness: `أثبتت المنهجية فعاليتها عالميًا في…، ويُعتبر أحدث مشروع
   أنجزناه في {الدولة} خير دليل على ذلك`
5. Asset-ownership: `لدى ديلويت مصفوفة لـ…` / `لدينا منصة إلكترونية تم تطويرها كأحد
   أصول ديلويت…`
6. Customizability: `يمكن تخصيص إطار {X} ليناسب حجم ونطاق احتياجات أي منظمة`
Continuation slides start with `و` or `اضافة لذلك،`. Latin names keep ©/®/™
(`StrategyByDesign©`, `Aerodynamics®`, `EVM™`); Arabic name first + (LATIN) acronym
in parentheses (SWOT، PESTEL، Problem Statement).

### Color-role grammar (what each color MEANS in diagrams)

- **Teal `0D8390` + dark teal `005253`/`004F59`** = process & governance machinery
  (chevrons, banners, cycle diamonds, risk cards, value trees). The "method engine".
- **Green ramp `046A38`→`26890D`→`43B02A`→`86BC25`** = staged progress/maturity —
  dark = early/foundation, bright = late/target; RTL ramps run right(dark)→left(bright).
- **`86BC25`** = highlight/endpoint: matrix header bars, selected list items, pyramid
  tops, final phases, funnel shortlists, underline strokes.
- **Blue `007CB0`** = current-state / PMO / technology domain (blue-dotted wheel skin
  for delivery/tech vs green-solid for strategy).
- **Black/near-black** = raw inputs or the deepest drill level.
- **Grays** (`53565A` text, `BBBCBC`/`D0D0CE` structure, `F2F2F2` panels) = neutral
  containers. **Saturated fills carry ONLY short white bold labels; all sentences live
  in light-gray panels** at 11–14pt.
- Legend discipline: every color/icon in a diagram must reappear in its text list.

### Archetype catalog (pick by logic type when drawing NEW frameworks)

| Logic | Archetype | Key specs |
|---|---|---|
| Cycle (N phases) | Wheel + diamonds | Arc track, numbered `005253` diamond nodes, hexagon hub for the continuous phase, phase labels 24pt bold flanking with **138pt white ghost numerals** behind |
| Progressive disclosure | Triptych | Same geometry ×3: overview → definition blocks (`005253` header bars + justified 14pt paragraphs) → question blocks (3–5 question bullets with small gray icons) |
| Time-staged strategy | Phase-band | 3 color-coded pills (blue→teal→dark = current→options→future) + 6 stage rects + double-headed arrows + 6-column question grid |
| Cascade | Staircase | 5 question boxes descending right→left, green→gray gradients, dashed loop-back arrows, group headers with green underline strokes |
| Applied proof | Proof-case slide | Immediately after the framework: 4 columns with `86BC25` header bars = the framework's questions, filled with a REAL reference project's answers + numbers-first stats |
| 2×2 analysis | SWOT matrix | Quadrant = narrow `86BC25` header bar + white circle icon badge + light-gray body panel (11pt, bullet + ➤ Wingdings sub-bullets) |
| Acronym framework | Photo banner | Full-width photo band with giant Latin capitals (P E S T E L) + one column per letter (green line icon + bold header + bullets); columns run LTR to match the Latin letters |
| N-step process | Chevron strip | Teal banner naming the methodology + N `chevron` shapes (teal, white bold, points LEFT) + light-gray body boxes + optional dashed-border checklist layer of icon cards |
| Criteria set | Chevron matrix | 8 homePlate arrow bars in 2 columns + center green pennant tab with rotated label |
| Composition | Hub-spoke wheel | Gray ring + N green-ramp circles (position encodes sequence) + legend-as-questions list with matching pill labels |
| Multi-step logic | Stacked bands | 2 numbered full-width light-gray strips, each band its own mini-diagram (⊕ additive chains, funnels with green chevron gates) |
| Value tree | EVM cascade | 3-level tree: teal root → teal L2 → black-gradient L3 boxes with Latin glosses; side photo panel with white stat claim (`أكثر من 500 مؤشر أداء`) |
| EN-native framework | Imported graphic | Keep the English Deloitte graphic; annotate in Arabic via a black header bar + color-matched bold lead-ins + hairline connectors to arc segments |
| Branded program | Q&A bars | 2 green `26890D` section bars (`ما هو برنامج X®؟` / `مكونات برنامج X®`) + scattered-bold paragraph + component rows color-matched to a dotted-node network diagram |
| Platform/tool | Screenshot showcase | Dark-green homePlate feature tabs + REAL product screenshots in thin gray borders (never redraw fake UI) |

Arrows: solid thin black elbow = main flow; **dashed = iteration/feedback**; gray
U-turn = rejected options; green `86BC25` chevrons = stage gates (point LEFT);
teal curved = cascade annotations; double-headed = interdependency. Numbered badges
everywhere. Rotated white side-labels + ghost numerals are the two permitted
decorative flourishes. Body may drop to 9pt inside explainer cards; titles/headers
never deviate from 28/16/14.

The **fixed six** always ship (they also appear inside the approach chapter):
project-management mechanism, risk management, escalation plan, quality plan,
collaborative working, knowledge transfer.

Recomputed per RFP: which frameworks + order; the proof-case slide (swap in a
reference project matching the client's geography/sector, real numbers); client-word
tweaks in titles (الأمانة/الوزارة/الجهة); footer string + © year. Everything else is
frozen library.

## 2. ملحق: نبذة عن ديلويت (11 slides — VERBATIM frozen pack)

Character-for-character identical across the reference decks. **Palette deviation
unique to this pack** (it comes from Deloitte's global brand template): alongside
`86BC25` it uses `009A44` (accessible green — stat numbers, country names), `3F3D56`
(navy-slate labels), `0097A9` teal, `262E3B` dark bands. Do NOT "correct" these to
the proposal palette — reproducing them as-is is what makes the section look like
genuine Deloitte collateral. Icon medallions: white circles with **gradient stroke
`86BC25`→`009A44`**, thin-line pictograms. Titles ~21pt black assertions.

Canonical sequence:
1. **Global KPI card row** — `ديلويت هي أكبر شركة خدمات مهنية في العالم`: green
   kicker `السنة المالية {YYYY}`; 5 rounded cards (icon medallion overlapping top
   edge; number 28pt bold `86BC25`; label 24pt `3F3D56`): الإيرادات 67.2 مليار دولار /
   +460,000 موظف / +92,000 موظف جديد / +150 دولة / 416 مليون دولار استثمارات مجتمعية.
   Green dot-scatter ornament bottom.
2. **Revenue breakdown** — `وصلت الإيرادات العالمية التراكمية في {YYYY} إلى {N} مليار
   دولار`: 3 white cards (`{القطاع}: {n.n} مليار دولار` parallel rows, values 18pt
   bold) + full-width `86BC25`→`009A44` gradient band with a 4-year dotted timeline.
   KEEP the brand-police footnote under the middle card — it screams authenticity.
3. **ME heritage** — `تمتلك ديلويت خبرة تقارب 100 سنة في الشرق الأوسط`: green display
   quote (24–31pt `86BC25`), ME choropleth (KSA darkest), left stat rail
   (+7,000 موظف / 41% نساء / 101 جنسية / 15 دولة / 23 مكتباً — numbers 28pt `009A44`).
4. **Office directory** — 15 countries / 24 cities, country names bold `009A44` 16pt,
   cities 16pt black; green display statement + `101 جنسية` medallion band.
5. **History & awards** — est. 1926 panel + `الجوائز` card with real Great Place to
   Work badges + تأثيرنا الداخلي/الخارجي columns.
6. **NSE parent slide** — display statement + 2 stat cards (numbers 44pt green).
   NOTE: the library title says `أفريقيا` where it means `أوروبا` — a frozen typo;
   fix it once in the library.
7. **Service dimensions hub** — `تقدم ديلويت خدماتها عبر 4 أبعاد رئيسية`: radial
   green disc + dotted-spiral halo (brand asset — reuse image, don't redraw) + 4
   quadrant lists.
8. **Industry matrix** — `تركز ديلويت على 5 مجالات عمل رئيسية و20 قطاعاً…`: 5 panels
   with 1pt `86BC25` borders. Never trim to the client's sector — breadth IS the
   message.
9–11. **AI trio** (kept even in non-AI proposals): AI powerhouse (4 KPIs 36pt green,
   dark alliance band with partner logos on white chips, ME presence columns), AI
   Institute research slide (report covers + academic logo wall), Trustworthy-AI
   wheel (Advise/Implement/Operate ring + 4×4 offering grid + pipe-separated enabler
   strips).

Update only fiscal-year figures when Deloitte publishes new numbers. Trim (only under
a page cap): AI trio first, then NSE.

## 3. ملحق: الشروط والأحكام (12 slides — legal pack, one atom changes)

Pure text pages: title `الشروط والأحكام` (20pt) + gray strapline `فيما يلي الشروط
والأحكام العامة لشركة ديلويت` — **both repeated verbatim on all 12 slides, no (1/N)
counters**. Body: **8pt** Sakkal Majalla, right-aligned (NOT justified), manual
hierarchical numbering typed as text (`1.` → `1.1.` → `1.1.1.` + `أ./ب./ج.`), ~10–18
clauses per slide, slide breaks falling mid-clause-family (the agreement is FLOWED
across 12 fixed frames, not re-edited per slide).

**The ONLY per-proposal edit**: the client legal name in clause 3.1, where
`(يشار اليه فيما بعد ب "العميل")` follows. Never re-word, never fix the legal pack's
typos, never add design — it must look like paralegal paste, not slideware. Flag to
the user if the RFP requires different terms.

## 4. ملحق: المستندات القانونية (9+ slides + closer)

One certificate per slide, title `المستندات القانونية | {اسم الشهادة}` (20pt).
**Scan centered, native aspect ratio, NO frame/border/shadow/caption** — the scan IS
the content. Two-page certificates go side-by-side on ONE slide, never two slides.
Canonical fixed order (always all 9):
السجل التجاري → شهادة العضوية في الغرفة التجارية → شهادة ترخيص استثمار خدمي →
شهادة الزكاة والدخل → شهادة التسجيل في ضريبة القيمة المضافة → شهادة المؤسسة العامة
للتأمينات الاجتماعية → شهادة الالتزام بحماية الأجور → شهادة التوطين → رخصة البلدية.
Then parse the RFP's متطلبات التأهيل for extra required certificates (e.g. شهادة
تصنيف مقدمي خدمات المدن، شهادة التصنيف الفني للمقاول) and append them with the same
breadcrumb title. Always use the LATEST scan of each document; **check validity
dates** — flag expired certificates to the user; never doctor a scan.

**Final slide of the deck** (always literally last): the fixed disclaimer text page —
Monitor Deloitte wordmark top-left, 6–8 right-aligned paragraphs at 10pt (DME/NSE/
DTTL structure + liability), **Arabic-Indic numerals in this prose only** (٥٠٠، ١٣٠
دولة، ٤١٠٬٠٠٠), closing `© {السنة} ديلويت آند توش (الشرق الأوسط)، جميع الحقوق
محفوظة.` Use the fuller (deck-2) version; recompute only the year.

## 5. Anti-patterns for this whole corporate layer

An AI-made giveaway would be: restyled T&C, captioned/bordered certificate scans,
`(1/12)` counters on the T&C, About slides rewritten or re-palettized, or the AI trio
dropped "for relevance". Never do any of these.
