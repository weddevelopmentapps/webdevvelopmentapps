# Section Playbook — النهج الذي سنتّبعه (Our Approach)

The technical heart (~18–19 slides): converts the RFP scope into tracks/phases with
named activities and BoQ-mapped deliverables. Structure: divider → overview → BoQ
mapping → (optional team/cost note) → detailed methodology pages.

## 1. Choose the delivery model (from the RFP's nature)

- **Workstream model** — continuous/parallel advisory services (deck 1): N `مسارات عمل`
  running concurrently over the duration. Naming: `مسار الإطلاق` +
  `مسار العمل الأول/الثاني/الثالث/الرابع` (ordinal words).
- **Phase model** — sequential build-and-handover (deck 2): N `مراحل` in sequence.
  Naming: `المرحلة صفر – الاطلاق` + `المرحلة الأولى…السادسة` (or digits 0–6).
- Fixed bookends in BOTH models: track/phase 0 = الإطلاق (launch); the last (or a
  dedicated) stream = التمكين المؤسسي / نقل المعرفة (institutional enablement /
  knowledge transfer).
- Track names: noun phrases in the RFP's own vocabulary. 3–6 substantive tracks.

## 2. Approach overview slide (archetype J)

Title: `سيتم تنفيذ المشروع عبر {N} مسارات رئيسية وخلال مدة زمنية تقدر بـ{X} أشهر`
(number + duration both from the RFP; if the RFP fixes them, echo exactly).
Body: N+1 column bands right→left (track 0 rightmost). Per column:
- Header chip: green gradient band (solid/darker for track 0), white bold name.
- Sub-track list: `{X.1} {اسم فرعي}` green bold 11–12pt + dense bullets (2–5 per
  sub-track, 10pt) previewing activities.
This slide compresses the whole chapter; every string on it must match the methodology
pages and the exec-summary slide B track list character-for-character.

## 3. BoQ deliverables slide

Title: `بناء على جدول الكميات، تم تفصيل المخرجات الرئيسية للنهج الذي سنتّبعه لكل
مسار/مرحلة`. Table mapping each track → its BoQ deliverables with quantities and
cadence (شهري/ربع سنوي/عند الطلب). Column headers from the RFP's own BoQ terms. Every
BoQ line must appear exactly once; quantities must sum to the RFP's totals.

Optional follow-up (deck 1 slide 47): a reassurance slide when the proposal proposes
deliverable quantities — `ونقترح هذه الكمية من المخرجات بنفس عدد فريق العمل والذي لا
يؤثر على تكلفة المشروع` — use when the RFP invites bidder-proposed volumes.

## 4. Detailed methodology pages (archetype K — the proposal's core evidence)

One series per track: `منهجية المشروع التفصيلية | {المسار/المرحلة} {ordinal} – {الاسم}
({i}/{n})`. Budget 1–3 pages per substantive track.

**Fixed page anatomy** (identical geometry on every page of the series):
- Header band + breadcrumb title.
- **Navigator ribbon** under the band: all N+1 track chips; active chip lit
  (white-on-green), others ghosted. The ribbon is how evaluators keep their place —
  never omit it, never let the highlight disagree with the breadcrumb.
- Main area (right ~75%): `الأنشطة:` then per sub-track a green bold header
  `المسار الفرعي {X.Y} | {الاسم}` + two-level bullets:
  - Level 1 (•): activities, verb-first (`العمل بشكل مباشر مع الإدارة العليا لتحديد…`,
    `إعداد ومراجعة…`, `عقد ورش عمل وجلسات تفاعلية مع…`), 5–10 per sub-track.
  - Level 2 (◦): concrete sub-steps (`تحويل القضايا العامة إلى أسئلة قابلة للتحليل
    والقياس.`, `تحديد نطاق كل دراسة وحدودها الزمنية والتنظيمية والجغرافية.`), 3–7 each.
- Left sidebar (~20%, `F2F2F2`): `المخرجات والنتائج:` + noun-phrase deliverables
  matching the BoQ table 1:1.
- Standard footers.

**Writing rules**: activities answer "what will you actually do with whom"; every
sub-track ends its bullet run with a quality/alignment closer (`ضمان اتساق مخرجات
الدراسات مع التوجهات الاستراتيجية لـ{الجهة}.`). No adjectives without mechanisms.

## 5. Launch-phase special pages (clone from library, adapt names)

The المسار/المرحلة صفر series includes, beyond its own (1/1) activities page, these
near-verbatim library pages (both reference decks carry them all):
1. `… | الاطلاق | آلية ادارة المشروع` — governance structure: committees, cadence,
   reporting lines diagram.
2. `… | الاطلاق | إدارة المخاطر والتحديات` — risk approach: identification → assessment
   matrix → mitigation plans → monitoring (`ويقترح تطبيق خطة ممنهجة لتحديد وتقييم
   المخاطر ووضع الخطط التصحيحية لها ومراقبتها`).
3. `… | الاطلاق | خطة إدارة الجودة والمخرجات` (deck 2) — quality gates for deliverables.
4. `… | الاطلاق | خطة إدارة التصعيد` — escalation levels pyramid.
And in the knowledge-transfer stream:
5. `… | {التمكين} | العمل التشاركي مع {الجهة}` — collaboration model (joint teams,
   co-location, shadowing).
6. `… | {التمكين} | منهجية نقل المعرفة` — knowledge-transfer methodology
   (`سيقوم فريق العمل بتطوير خطة نقل المعرفة وتطوير الكوادر والتي تهدف الى تطوير
   الكوادر بشكل مستدام`).

## 6. Cross-consistency contract (verify before QA)

- Track names identical across: exec summary slide B, PoV pivot slide, approach
  overview, navigator ribbons, breadcrumb titles, BoQ table, Gantt phase bands.
- Deliverable names identical across: BoQ slide, methodology sidebars, Gantt markers.
- Durations identical across: overview title, Gantt title, exec summary.
- Sub-track numbering `X.Y` continuous and unique.
