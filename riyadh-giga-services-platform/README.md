# منصة الرياض الموحدة لتمكين المشاريع الكبرى — أمانة منطقة الرياض

**Riyadh Unified Giga-Projects Enablement Platform (RGP)** — المنصة الرقمية الموحدة لإدارة وتمكين المشاريع الكبرى في مدينة الرياض، تنفيذًا للمسار التاسع من كراسة **«حوكمة العلاقة مع المشاريع الكبرى» (RRDC-RFX-00540-2)** الصادرة عن شركة ريمات الرياض للتنمية لصالح أمانة منطقة الرياض.

> **نسخة تجريبية للعرض** — الحسابات والطلبات والبيانات افتراضية بالكامل لأغراض العرض، وقنوات التكامل (GIS، التراخيص، CRM) محاكاة موسومة بذلك في الواجهة. الربط الفعلي بأنظمة الأمانة يتم في مرحلة لاحقة عبر طبقة المهايئات الجاهزة (انظر «جاهزية الربط» أدناه).

## التشغيل

- **بدون أي متطلبات:** افتح `index.html` مباشرة (نقرة مزدوجة). الملف مكتفٍ ذاتيًا بالكامل — الخطوط العربية ومكتبة الرسوم والشعار وبيانات العرض مضمنة داخله، ويعمل دون إنترنت خلف أي سياسة أمنية.
- التعديلات (الطلبات، القرارات، التحديات…) تُحفظ محليًا في المتصفح. من الملف الشخصي: **تصدير/استيراد** JSON و**استرجاع بيانات العرض**.
- إعادة البناء من المصدر: `python3 generate_data.py && python3 build.py`

## تجربة العرض الكاملة

1. من شاشة الدخول اختر هوية **م. بدر الراشد** (مطور — مجموعة روشن) أو أي مستفيد آخر.
2. **طلب جديد** ← اختر المشروع والمرحلة (قبل التطوير) ← الخدمة (إصدار قرار مساحي) ← عبّئ النموذج الذكي ← أرفق المستندات ← راجع وقدّم. يظهر رقم الطلب `RQ-2026-XXXX` وتاريخ الاستحقاق وفق اتفاقية مستوى الخدمة.
3. سجّل الخروج وادخل بهوية **سارة القحطاني** (أخصائي بلدي): قائمة الطلبات ← افتح الطلب ← إسناد وبدء الفرز ← تحقق من المستندات ← بدء المراجعة ← جاهز للقرار ← **اعتماد** (يصدر رقم وثيقة `RGP-2026-XXXX` وشهادة قابلة للطباعة) أو **إعادة للعميل** (قائمة نواقص إلزامية وتتوقف المدة) أو **رفض** (سبب + سند نظامي إلزاميان).
4. ادخل بهوية **م. عبدالعزيز الحمدان** (مدير مكتب المشاريع الكبرى): لوحة القيادة بمؤشرات المسار التاسع الستة، خريطة مشاريع الرياض، التصعيدات، لوحة التحديات، التقارير.
5. جرّب أيضًا: الجهة الخارجية (شركة الكهرباء — تسجيل المرئيات على الإحالات)، والمستخدم المشاهد (مكتب الأمين — قراءة فقط).

كلمة مرور جميع الحسابات التجريبية: `Demo@2026` (أو دخول بنقرة واحدة من بطاقات الهويات).

## الأدوار والصلاحيات (المسار التاسع — مستويات الصلاحيات)

| الدور | المعرف | التغطية |
|---|---|---|
| مدير المنصة — مكتب المشاريع الكبرى | `platform_manager` | لوحة القيادة، سجل المشاريع، التحديات، المؤشرات، التقارير، دليل الخدمات، سجل التدقيق، الإعدادات، وكل صلاحيات الأخصائي |
| جهة الأمانة — أخصائي بلدي | `amanah_specialist` | قائمة طلبات بمسار أولوية، مساحة مراجعة ثلاثية، قرارات محكومة |
| ممثل المشروع (4 شخصيات: جهة مشروع كبير، مطور، مستثمر، مدير أصول + مكتب هندسي بالإنابة) | `project_rep` | بوابة المستفيد، مستكشف الرحلة، معالج الطلب بخمس خطوات، المتابعة، التحديات |
| جهة خارجية | `external_entity` | صندوق الإحالات وتسجيل المرئيات (قناة محاكاة) |
| مستخدم مشاهد | `viewer` | الملخص التنفيذي قراءة فقط دون بيانات تعريفية |

## رحلات المستفيدين (الدليل الاسترشادي — يوليو 2026)

- **مشاريع التخطيط**: الخطوات السبع الرسمية بمددها (قرار مساحي 10، محددات 5، لجنة NPX ‏10، اعتماد أولي 15…) والمسارات الثلاثة لاستكمال الاعتماد، بما فيها مسار الاعتماد الابتدائي والإفراغ التدريجي بخطواته التسع (اعتماد شبكات 28 يومًا، إفراغ جزئي ≥25%).
- **مشاريع البناء**: رخصة البناء بمتطلباتها الرسمية، التصاريح البيئية، تصاريح التمكين الإنشائي (رافعات، حفريات، إغلاق طرق، سياج…)، إيصال التيار، شهادة الإتمام والإشغال.
- **المستثمر العقاري**: ما بعد التعاقد (تجهيز وتشغيل) ثم التجديد أو الإنهاء وتسليم الموقع لمكاتب مدينتي.
- **التشغيل وإدارة الأصول**: رخص الأنشطة والإشغال، الفعاليات، الامتثال الدوري، التجديد.
- **المشاريع الصناعية**: داخل نطاق مُدن وخارجه.

## جاهزية الربط (المرحلة القادمة)

طبقة البيانات معزولة خلف واجهة `StorageAdapter` واحدة (`src/js/02-store.js`) مع موصلات تكامل موسومة «محاكاة» (GIS، التراخيص، أنظمة الأمانة، أنظمة المطورين، التصاريح، CRM). الربط الفعلي بنظام إدارة علاقات العملاء في الأمانة يستبدل مهايئ `localStorage` بمهايئ REST دون تعديل أي شاشة، ويستبدل الدخول التجريبي بالنفاذ الوطني الموحد خلف الواجهة نفسها.
