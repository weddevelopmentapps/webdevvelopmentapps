# منصة استدامة كفاءة الإنفاق — الهيئة الملكية لمدينة الرياض

**RCRC Spending Efficiency Sustainability Platform** — المنصة المركزية لأتمتة ممارسات كفاءة الإنفاق وأعمال فريق كفاءة الإنفاق، دعماً لمشروع **«تمكين استدامة كفاءة الإنفاق»** (كراسة رقم 20000424) واستهدافاً لدرجة **«متميز»** في المؤشر الوطني لبرنامج ركائز استدامة كفاءة الإنفاق الصادر عن هيئة كفاءة الإنفاق والمشروعات الحكومية (إكسبرو).

> ⚠️ **البيانات الحالية تجريبية لأغراض العرض** وتُستبدل بالبيانات الفعلية عند التشغيل (انظر «استبدال البيانات» أدناه). الأرقام والمبادرات والدرجات أمثلة واقعية البنية وليست بيانات رسمية.

## التشغيل

- **بدون أي متطلبات:** افتح `index.html` مباشرة (نقرة مزدوجة). الملف مكتفٍ ذاتياً بالكامل — الخطوط العربية ومكتبة الرسوم مضمنة داخله، ويعمل دون إنترنت خلف أي سياسة أمنية.
- تُحفظ التعديلات (درجات التقييم، المبادرات، الوثائق، الاجتماعات…) محلياً في المتصفح، مع أزرار **تصدير / استيراد** (JSON) و**استرجاع** بيانات العرض الأصلية و**طباعة**.

## الوحدات الاثنتا عشرة

| الوحدة | التغطية |
|---|---|
| **الرئيسية** | مركز قيادة: مؤشر الجاهزية نحو «متميز»، مسار الأثر المالي، خط أنابيب المبادرات، تنبيهات مشتقة آلياً، العد التنازلي لدورة التقييم، قراءة تنفيذية |
| **ركائز الاستدامة** | محرك التقييم للركائز السبع (دورة حياة الإنفاق): 33 معياراً بدرجات قابلة للتحديث في وضعي **التقييم الذاتي** و**محاكاة التقييم المستقل**، الوثائق الداعمة لكل معيار بحالاتها، إجراءات المعالجة، خريطة النضج، مصفوفة المعايير، فجوات الوصول إلى «متميز» |
| **المبادرات** | دورة الحياة الكاملة (بطاقة الفرصة ← الدراسة ← الميثاق والاعتماد ← التنفيذ ← قياس الأثر ← الإقفال) بلوحة كانبان وسجل قابل للبحث، مع **بوابة التحقق المالي قبل الاعتماد**، رايات التأخر/التعثر، طلبات التغيير، وإضافة/تعديل المبادرات |
| **الأثر المالي** | سجل الوفورات (وفر مباشر / تجنب تكلفة / تعظيم إيراد) بخطوط أساس موثقة، شلال بناء الأثر (محدد ← معتمد ← محقق ← موثق)، ونسبة الأثر من الميزانية المعتمدة |
| **طلبات التمويل** | لائحة التعقب مع **بوابة اكتمال الدراسات الخمس ودراسة السعة والطلب** وسلسلة المراجعة الرباعية (المقيّم ← قائد الفريق ← المالية ← المسؤول الأول) ومسار الإعادة للاستكمال |
| **الدراسات** | سجل دراسات السعة والطلب (7 خطوات حسب فئة الأصول) والدراسات الخمس والهندسة القيمية بنسب اكتمال |
| **الخدمات** | دليل الخدمات مع تكلفة المعاملة والحجم والتكلفة الإجمالية ونقاط المراجعة وتصنيف الجودة والنسبة الرقمية |
| **الميزانية والمراجعة** | أبواب الميزانية مع عوامل التكلفة ومسببات الطلب، وسجل مراجعات الإنفاق بفرصها ودروسها |
| **مؤشرات الأداء** | العائلات الأربع من النموذج التشغيلي لإكسبرو: الأثر المالي المحقق، الالتزام بالسياسات، تحسن الممارسات (15 مؤشراً)، الالتزام بالمبادرات — بمعادلاتها واتجاهاتها الزمنية |
| **الحوكمة** | التنظيم الإداري (الخيار الأول — وحدة مركزية)، ملاك الركائز، اللجنتان الإشرافية والتوجيهية بسجل اجتماعات وقرارات قابل للإضافة، وسلم التصعيد الثلاثي مع إكسبرو |
| **القدرات والثقافة** | مصفوفة المهارات، الخطة التدريبية، حلقة قياس الوعي، سلم التبني (مستهدف «تبني» 2026–2027)، آلية التحفيز، يوم كفاءة الإنفاق |
| **التقارير** | مولّد تقارير حية جاهزة للطباعة: جاهزية الركائز، الربع سنوي، السنوي 2026، حزمة منصة فرق كفاءة الإنفاق |

## مواءمة نطاق العمل (المسار الثالث — أتمتة المنهجيات)

| متطلب الكراسة | مكانه في المنصة |
|---|---|
| أتمتة دراسات السعة والطلب والدراسات الخمس | وحدة الدراسات + بوابة طلبات التمويل |
| أتمتة دورة حياة مبادرات كفاءة الإنفاق (تقديم، تحليل، وثائق، أثر مالي، تتبع، مالك) | وحدة المبادرات + الأثر المالي |
| أتمتة آلية التحفيز | القدرات والثقافة (آلية التحفيز) |
| أتمتة دراسة وتحليل طلبات التمويل | طلبات التمويل (سلسلة المراجعة والبوابة) |
| أتمتة التقييم الذاتي في برنامج الركائز وأرشفة الوثائق | ركائز الاستدامة (وضعا التقييم + سجل الوثائق) |
| أتمتة مراجعة الإنفاق | الميزانية والمراجعة (سجل المراجعات) |
| التقارير الإدارية وتقارير إكسبرو | التقارير (4 قوالب حية) |
| أتمتة مراجعة الخدمات ونقاط أدائها | الخدمات |
| تحليل مؤشرات الأداء على كافة المستويات | مؤشرات الأداء (العائلات الأربع) |

## البنية والبناء

```
rcrc-spending-efficiency/
├── index.html          # الناتج النهائي — مكتفٍ ذاتياً (1.5 م.ب)
├── generate_data.py    # مصدر الحقيقة الوحيد للبيانات + تأكيدات التسوية
├── data.json           # ناتج المولّد
├── build.py            # يجمّع src/ + vendor/ + data.json → index.html
├── src/                # styles.css · markup.html · app.js
└── vendor/             # ECharts 5 + الخطوط العربية المضمنة (Cairo / IBM Plex Sans Arabic)
```

إعادة البناء بعد أي تعديل:

```bash
python3 generate_data.py   # يعيد توليد data.json ويتحقق من تسوية كل الأرقام
python3 build.py           # يعيد تجميع index.html
```

**تأكيدات التسوية:** درجة كل ركيزة = متوسط معاييرها، والدرجة الشاملة = متوسط الركائز؛ مجاميع الأثر المالي (محدد/معتمد/محقق/موثق) مشتقة حصراً من سجل المبادرات وتتطابق مع السلاسل الشهرية وتوزيعات الفئات والبرامج؛ نسبة الالتزام بالمبادرات ونسبة اكتمال طلبات التمويل قابلة لإعادة الاحتساب من السجلات نفسها. أي خلل يوقف التوليد.

## استبدال البيانات التجريبية بالفعلية

1. **الطريقة المفضلة:** عدّل الجداول أعلى `generate_data.py` (المعايير، المبادرات، الطلبات، الخدمات، الأبواب، المؤشرات…) ثم أعد البناء — التأكيدات تضمن التسوية.
2. **مباشرة:** استورد ملف JSON بنفس البنية من زر «استيراد» داخل المنصة (يُحفظ محلياً في المتصفح).
3. عند الجاهزية للتشغيل المؤسسي: تُستبدل طبقة البيانات بواجهات ربط مع منصة اعتماد ومنصة فرق كفاءة الإنفاق ومنصة برنامج الركائز والأنظمة المالية الداخلية (النموذج التشغيلي لإكسبرو يتطلب انسياب النتائج «تلقائياً»).

## مستوى الجودة المتحقق

- صفر أخطاء في وحدة تحكم المتصفح عبر جميع الوحدات والأدراج والنماذج (فحص آلي Chromium بلا رأس، 1600×1000 و390×844).
- عربي RTL كامل: الرسوم البيانية بقواعد RTL (أشرطة تنمو من اليمين، المحاور والوسائل معكوسة)، أرقام لاتينية بفواصل آلاف داخل نص عربي.
- حفظ محلي فوري، تصدير/استيراد، طباعة، توجيه روابط (#tab)، دعم `prefers-reduced-motion`، ولوحة مفاتيح (Esc للإغلاق).
- الشعار الرسمي للهيئة مضمّن (`assets/logo-emblem.png` في الترويسة والأيقونة، و`assets/logo-full.png` في ترويسات التقارير) ويُدمج تلقائياً داخل الملف الواحد عند البناء.
